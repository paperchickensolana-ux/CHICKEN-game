# CHICKEN TO THE MOON — Web Game

Mini-jeu web HTML/CSS/JavaScript sans framework.

## Lancer sur Windows

1. Décompresse le ZIP.
2. Ouvre le dossier `chicken-web-game`.
3. Double-clique sur `index.html`.

Pour un meilleur test local, tu peux aussi utiliser VS Code + extension Live Server.

## Contrôles

- Flèche ↑ / W / Espace : monter
- Flèche ↓ / S : descendre
- Mobile : boutons FLY / DOWN

## Fichiers

- `index.html` : interface
- `style.css` : design
- `game.js` : logique du jeu
- `assets/chicken-cover.png` : image fournie par toi
